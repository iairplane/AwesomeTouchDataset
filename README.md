# AwesomeTouchDataset

一份视觉–触觉数据集索引。首页总览收录 18 套通过筛选的数据和 10 套扩展参考，列出发布规模、相机位置、文件格式、直接提供的字段和可计算的数据。点击名称可查看采集设备、视频与下载入口。

目录依次列出公开可下载、需登录或申请、许可待核的数据。每组按发布时长降序，只有段数的放在组末，按段数降序。可按人手手套、手持夹爪、压力平板、机器人和混合采集查找。样本视频与完整训练数据的来源分别列出。

论文读本收录 20 篇中文全文译稿和 17 篇研究导读。调研页提供实验对照和交互引用图谱，全文证据可下载为 CSV。

网站为静态页面，入口是仓库根目录的 `index.html`。GitHub Pages 选择 `main` 分支和 `/(root)`。
