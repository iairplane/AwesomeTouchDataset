# AwesomeTouchDataset

一份视觉–触觉数据集索引。首页总览收录 18 套通过筛选的数据和 10 套扩展参考，列出发布规模、相机位置、文件格式、直接提供的字段和可计算的数据。点击名称可查看采集设备、视频与下载入口。

- [浏览 GitHub Pages](https://iairplane.github.io/AwesomeTouchDataset/)
- [数据集总览](https://iairplane.github.io/AwesomeTouchDataset/#overview)
- [预训练分组](https://iairplane.github.io/AwesomeTouchDataset/#pretraining)
- [论文引用与数据用途](https://iairplane.github.io/AwesomeTouchDataset/#citations)
- [TachinTech 混合采集专题](https://iairplane.github.io/AwesomeTouchDataset/#tachintech)
- [下载筛选 CSV](data/datasets.csv)
- [媒体来源与署名](MEDIA.md)

目录先排公开可下载的数据，其次是需申请和许可待核。每档按发布时长降序，时长未核实的按段数排列在后。可按人手手套、手持夹爪、压力平板、机器人和混合采集查找。样本视频与完整训练数据的来源分别列出。

网站为静态页面，入口是仓库根目录的 `index.html`。GitHub Pages 选择 `main` 分支和 `/(root)`。
